    Asisten AI (Gemini)

    Belum diatur

    Laporan ditulis oleh Google Gemini (gratis) dari catatan kegiatan hari itu. Kunci API disimpan terenkripsi dengan kata sandi panel. Catatan kegiatan hari itu dikirim ke Google saat tombol Buat dengan AI ditekan; pada layanan gratis, Google dapat memakai data itu untuk meningkatkan produknya.

    Cara mendapatkan kunci API Gemini (gratis)
    1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
    2. Klik Create API key. Bila diminta memilih project, pilih project Google Cloud yang sudah ada (misalnya yang dipakai untuk Google Drive) atau buat baru.
    3. Klik ikon salin di samping kunci (biasanya diawali AIza, sekitar 39 karakter). Tidak perlu kartu kredit atau billing.
    4. Tempel di kolom di atas, isi kata sandi panel, lalu klik Simpan kunci. Panel otomatis memilih model Gemini Flash terbaru.

    Salinan ke Google Drive

    Belum diatur

    Foto asli setiap kegiatan ikut disimpan ke Google Drive Anda, di folder Laporan Magang/tanggal. Panel hanya bisa mengakses file yang dibuatnya sendiri, bukan seluruh isi Drive.

    Buka folder Drive ↗
    Cara mendapatkan Client ID (sekali saja, ±15 menit)
    1. Buka Google Cloud Console, buat project baru, misalnya laporan-magang.
    2. Menu APIs & Services → Library: cari Google Drive API, klik Enable.
    3. Menu Google Auth Platform (atau OAuth consent screen): isi nama aplikasi dan email Anda, pilih External. Di bagian Audience / Test users, tambahkan email Google Anda sendiri.
    4. Menu Clients (atau Credentials → Create credentials → OAuth client ID): pilih Web application. Di Authorized JavaScript origins isi . Klik Create.
    5. Salin Client ID (berakhiran .apps.googleusercontent.com) ke kolom di atas, lalu klik Simpan dan Hubungkan & tes.

    Ganti kata sandi panel
