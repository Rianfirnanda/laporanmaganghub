Pengaturan pertama di perangkat ini

Masukkan token GitHub lalu buat kata sandi panel. Token akan dienkripsi dengan kata sandi ini sebelum disimpan di perangkat.

Baru menyalin repo ini untuk laporan Anda sendiri?
  1. Pastikan repo sudah milik akun GitHub Anda (Use this template atau Fork) dan Settings → Pages sudah memakai Deploy from a branch → main → / (root).
  2. Buat token di GitHub → Fine-grained tokens: Repository access → Only select repositories → pilih repo Anda; Permissions → Contents: Read and write. Salin tokennya (github_pat_…).
  3. Isi username, nama repo, dan token di bawah, lalu buat kata sandi panel (khusus perangkat ini).
  4. Setelah terhubung, panel menawarkan Mulai baru: data pemilik lama dikosongkan dan profil Anda diisi.

    Belum diatur

    Dua layanan gratis dipakai berlapis. Gemini dicoba lebih dulu, lalu model Flash lain bila sedang sibuk (galat 503) atau kuotanya habis. Setelah itu Groq sebagai cadangan. Isi salah satu atau keduanya; dengan keduanya, laporan hampir tidak pernah gagal. Kunci disimpan terenkripsi dengan kata sandi panel. Catatan kegiatan dikirim ke layanan AI untuk ditulis ulang.

    Cara mendapatkan kunci Gemini (gratis)
    1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
    2. Klik Create API key, pilih project yang ada atau buat baru. Tidak perlu kartu kredit.
    3. Salin kunci (diawali AIza), tempel di atas, isi kata sandi panel, lalu Simpan kunci.
    Cara mendapatkan kunci Groq (gratis, cadangan)
    1. Buka console.groq.com/keys dan masuk (bisa dengan akun Google). Tidak perlu kartu kredit.
    2. Klik Create API Key, beri nama misalnya laporan-magang, lalu salin kuncinya (diawali gsk_). Kunci hanya ditampilkan sekali.
    3. Tempel di kolom Groq, isi kata sandi panel, lalu Simpan kunci.

    Memeriksa…

    HP atau laptop ini akan menerima notifikasi setiap laporan harian AI selesai atau gagal, setiap ada perubahan data, dan saat website diperbarui. Notifikasi dikirim GitHub Actions, jadi tetap datang walau website sedang tidak dibuka.

    Browser ini belum mendukung notifikasi push. Di iPhone/iPad (iOS 16.4+), buka website di Safari → Bagikan → Tambahkan ke Layar Utama, lalu buka panel dari ikon itu.

    1. Kunci notifikasi (sekali untuk semua perangkat)

    Salin kunci rahasia ini sekarang. Kunci hanya tampil sekali dan tidak disimpan di mana pun.

    1. Buka GitHub → Settings → Secrets and variables → Actions → New repository secret.
    2. Name: VAPID_PRIVATE_KEY, Secret: tempel kunci di atas → Add secret.
    3. Kembali ke sini, lalu aktifkan notifikasi di perangkat (langkah 2).

    Google Drive tanpa login (Apps Script)

    Belum diatur

    Disarankan. Sebuah skrip kecil di akun Google Anda menerima foto dari panel dan menyimpannya ke Drive, jadi tidak perlu login Google setiap mengunggah. Skrip dilindungi kunci rahasia yang dibuat panel.

    1. Ketuk Salin kode skrip (kunci rahasia sudah terisi di dalamnya).
    2. Buka script.google.com → proyek baru → hapus isi Code.gs → tempel kode.
    3. Deploy → Deployment baru → Aplikasi web. Jalankan sebagai: Saya; akses: Siapa saja (bukan "Siapa saja yang memiliki Akun Google") → Deploy → izinkan akses (pilih akun → Lanjutan → Buka … (tidak aman) → Izinkan).
    4. Ketuk Cek URL: tab baru harus menampilkan "Penerima foto Laporan Magang aktif."
    5. Salin URL aplikasi web (berakhiran /exec) ke kolom di bawah, isi kata sandi panel, lalu Simpan & tes.

    Salinan ke Google Drive

    Belum diatur

    Foto asli setiap kegiatan ikut disimpan ke Google Drive Anda, di folder Laporan Magang/tanggal. Bila Apps Script (kartu di atas) sudah diatur, itulah yang dipakai. Cara lama di bawah ini memakai login Google (Client ID) dan perlu izin ulang tiap ±1 jam.

    Buka folder Drive ↗

    Cara mendapatkan Client ID (sekali saja, ±15 menit)
    1. Buka Google Cloud Console, buat project baru, misalnya laporan-magang.
    2. Menu APIs & Services → Library: cari Google Drive API, klik Enable.
    3. Menu Google Auth Platform (atau OAuth consent screen): isi nama aplikasi dan email Anda, pilih External. Di bagian Audience / Test users, tambahkan email Google Anda sendiri.
    4. Menu Clients (atau Credentials → Create credentials → OAuth client ID): pilih Web application. Di Authorized JavaScript origins isi . Klik Create.
    5. Salin Client ID (berakhiran .apps.googleusercontent.com) ke kolom di atas, lalu klik Simpan dan Hubungkan & tes.
